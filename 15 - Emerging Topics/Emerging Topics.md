# Emerging Topics

> **Navigation:** [[Agentic AI Roadmap]] → Emerging Topics
> **Prev:** [[System Design for AI-Native Applications]] | **Next:** —

---

AI moves fast. New model APIs, protocols, patterns, and product primitives show up constantly. The 14 core pillars stay stable; **this folder is the overflow lane** for things that are new, still forming, or not yet worth a permanent home in a pillar.

## How to use this folder

1. **Capture here first** — when something new appears (a capability, protocol, pattern, or tool class), add a note using [`_template.md`](../_template.md).
2. **Date it** — prefer filenames like `2026-09 - Topic Name.md` so recency is obvious.
3. **Keep it honest** — mark hype vs durable mechanism. Ask: will a backend engineer still need this in 12 months?
4. **Graduate when stable** — once the idea has a clear place (e.g. a new retrieval pattern → RAG, a new harness protocol → Orchestration), move or merge it into the right pillar and link back from here.

## What belongs here

- Brand-new model capabilities or API primitives
- New agent / tool protocols beyond what's covered in core notes
- Emerging eval, memory, or orchestration patterns
- Important industry shifts worth tracking before they settle

## What does not belong here

- Deep dives that already fit pillars 01–14 — put them there
- Vendor changelog spam with no engineering implication
- Pure product marketing with no mechanism to learn
